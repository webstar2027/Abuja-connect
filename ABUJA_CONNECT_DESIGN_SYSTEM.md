# Abuja Connect Design System — Current
- Overall light theme, white page backgrounds.
- Login/create-account surfaces: frosted white liquid-glass effect, blur, reflection and soft shadow.
- Royal blue #2563EB primary; coral red #E63950; violet #8B5CF6 Premium; teal #14B8A6 success/online; ice #F4F7FB.
- Navigation uses clean SVG line icons; no emojis in the navigation.
- Responsive desktop sidebar and mobile fixed bottom navigation.
- Dashboard views: Home, Discover, Encounters, Matches, Chats, My Profile, Premium.
- Premium plans are an authenticated dashboard view, not a public section hidden behind auth-only CSS.
- Free: signup, profile, photo gallery, Discover, Encounters/likes, Matches.
- Premium: messaging, both reading and sending.
- Chat: clean message bubbles, profile header, composer. Free users see a locked composer and subscription prompt.
- Paystack checkout remains server-verified; never place secret keys in public assets.
