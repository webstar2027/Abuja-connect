# Abuja Connect Design System

## Core theme
- White/light canvas across the entire site; no dark-mode backgrounds.
- Login and account creation use white liquid-glass surfaces with translucent layers, blur, soft reflections, and subtle shadows.
- Main interface accents: royal blue (#2563EB), coral red (#E63950).
- Premium accents: violet (#8B5CF6).
- Positive/online indicators: teal (#14B8A6).
- Section surfaces: ice grey (#F4F7FB), used sparingly.
- Typography is dark navy-ink (#172B49) on light surfaces for contrast.

## Feature access
- Free: registration, profile, photos, Discover, Encounters (Like/Pass), Matches.
- Premium: messaging and subscriber features. Messaging remains subscription-gated.
- Paystack is retained for subscription checkout and server-side verification.

## UI guidelines
- Rounded cards, light borders, modest shadows, generous spacing.
- Avoid large saturated blocks; keep blue/red/violet/teal accents restrained.
- Mobile layouts remain responsive and tap-friendly.
