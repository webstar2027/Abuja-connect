ABUJA CONNECT - TELEGRAM MINI APP SETUP

This build includes Telegram WebApp SDK initialization and Telegram/mobile layout support.

To open Abuja Connect inside Telegram:
1. Open @BotFather in Telegram and select @Abujaconnect_Bot.
2. Use /myapps or /setmenubutton and set the Mini App URL to https://abujaconnect.onrender.com
3. Use the website URL as the Web App URL/domain. BotFather may prompt to set the domain first with /setdomain.
4. Test by opening your bot and tapping its Menu button.

Do not put the bot token in website files or public GitHub code. The Telegram WebApp SDK is client-side and does not require the bot token in this website.

Existing Supabase auth, profiles, messages, and payment code are retained from the included project snapshot. This redesign does not run database migrations or delete user data.
